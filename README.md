Eventra - Event Booking Dashboard
 
Eventra is a modern and responsive event booking dashboard developed using HTML5, CSS3, Tailwind CSS, and JavaScript. The application provides users with an intuitive platform to discover events, manage bookings, view tickets, and monitor event-related activities through a clean and engaging interface.
 
## 🚀 Features
 
### Dashboard Overview
- Responsive three-column dashboard layout
- Modern and clean user interface
- User profile and quick actions panel
- Event statistics and analytics cards
 
### Event Management
- Browse upcoming events
- Featured event recommendations
- Event details and venue information
- Event category exploration
 
### Booking Management
- Recent bookings table
- Ticket status tracking
- Booking history overview
- Ticket management actions
 
### Interactive Features
- Dynamic UI interactions using JavaScript
- Search and filter components
- Responsive navigation menu
- Event booking simulation
 
## 🛠️ Built With
